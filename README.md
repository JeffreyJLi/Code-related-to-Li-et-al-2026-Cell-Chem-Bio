# Analyzing bulk RNA-seq data from Li et al. (2026)

The code in this repo was used to analyze the bulk RNA-seq experiment described in Li et al. (2026).

## Overall experiment design + how it relates to DESeq2

HEK293T cells were pre-treated with either DMSO or ZAKi (this will be referred to as "**inhibitor**" in our DEseq2 design formula) for 1 h before treating with ANS, EME, or DDB ("**drug**" in our DESeq2 design formula). 

Thus, our DESeq2 design formula will be "**~drug + inhibitor + drug:inhibitor**".

## Project directory structure

This RNA-seq project is organized in the following way:
```
/RNA-seq project/
  /scripts/
    Contains this Github repo (described in this README)
  /gencode_human_genome
    Contains GRCh38.primary_assembly.genome.fa and gencode.v46.primary_assembly.annotation.gtf files.
  /00_raw_data/
    Contains raw .fastq.gz files of raw sequencing reads+ their associated .md5 checksums
  /01_md5_check/
    Contains summary .log file generated by 01_checkmd5.sh
  /02_fastqc/
    Contains fastqc .html summaries of each .fastq.gz file in 00_raw_data
  /03_trimmed/
    Contains trimmed .fastq.gz files after running 03_cutadapt.sh, as well as the summary logs of each run.
  /04_STAR_genome_indices/
    Contains files generated by STAR --runMode genomeGenerate, which generates genome indices prior to alignment
  /05_STAR_alignments/
    Contains .bam alignment and .bam.bai index files of STAR alignments, sorted by coordinate as generated by 05_STAR_alignment.sh, 05b_STAR_tabulate_uniquely_mapped_reads.sh, and 
    05c_STAR_samtools_index.sh. 
  /06_featureCounts/
    Contains individual .txt files of the # of reads per gene PER .bam file, as calculated by the featureCounts package for each condition. This is not used for DESeq2.
  /06c_featureCounts_countMatrix/
    Contains a single .txt file of the # of reads per gene across ALL .bam files (all conditions), as calculated by featureCounts package. This is used in DESeq2.
```

## Pipeline used:

Scripts not listed here were not used in the final pipeline.

- **01_checkmd5.sh**: This is a basic script to cross-check the md5sum .md5 files provided by Genewiz with their associated actual .fastq.gz files. This ensures that the data was downloaded correctly from Genewiz. 

- **02_fastqc.sh**: This runs fastqc on each .fastq.gz file from Genewiz.

- **03_cutadapt.sh**: This uses cutadapt to trim the reads.

- **04_STAR_generate_genome_index.sh**: Generates genome indices of the GRCh38 human reference genome (from) using STAR. This is required for STAR alignment later.

- **05_STAR_alignment.sh**: Aligns reads to GRCh38 human genome using STAR.

  - **05b_STAR_tabulate_uniquely_mapped_reads.sh**: Calls a custom python script (`tabulate_uniquely_mapped_reads_05b.py`) to write the uniquely-mapped reads field from each STAR alignment into a separate .tsv file as a nice summary of the alignments.
  
  - **05c_STAR_samtools_index.sh**: Uses `samtools index` to generate .bam.bai files for the coordinate-sorted .bam files generated by STAR
  
  - **05d_STAR_cleanup.sh**: Cleans up the /05_STAR_alignments/ directory, moving log files into appropriate sub-folders.

- **06c_featureCounts_countMatrix.sh**: Counts the # of reads per gene across ALL .bam files (all conditions) and generates a countMatrix in a .txt file. This will serve as input for DESeq2

- **08_main_multiVariate_DESeq2.R**: The main file that calls sub-scripts (`08[a-z]_*.R` scripts) to run DESeq2 on the featureCounts countMatrix file and generate plots.
